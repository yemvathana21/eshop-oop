# ជំពូកទី ១៖ សេចក្តីផ្តើម (Chapter I: Introduction)

សព្វថ្ងៃនេះយើងឃើញថា វិស័យបច្ចេកវិទ្យា កំពុងតែមានការរីកចម្រើនឥតឈប់ឈរ ពីមួយថ្ងៃទៅមួយថ្ងៃ។ បណ្តាក្រុមហ៊ុន សហគ្រាសតូច ធំ អាជីវកម្ម អង្គការ និងស្ថាប័នផ្សេងៗនៅលលើពិភពលោក តែងតែផ្សាភ្ជាប់យ៉ាងជិតស្និតទៅនឹងវិស័យនេះ។

ទន្ទឹមនឹងនេះ នៅក្នុងប្រទេសកម្ពុជាយើង វិស័យបច្ចេកវិទ្យាក៏កំពុងតែរីកចម្រើនជាបន្តបន្ទាប់ទៅតាមនោះដែរ ជាពិសេសគឺការផ្លាស់ប្តូរពីការលក់ដូរដោយផ្ទាល់ មកជាការលក់ដូរតាមប្រព័ន្ធអនឡាញ (E-Commerce)។ ការទិញទំនិញតាមអ៊ីនធឺណិតបានក្លាយជាផ្នែកមួយយ៉ាងសំខាន់នៃជីវភាពរស់នៅរបស់ប្រជាជន ដែលផ្តល់ភាពងាយស្រួល ចំណេញពេលវេលា និងមានជម្រើសច្រើន។ អាស្រ័យហេតុនេះហើយ ទើបក្រុមយើងខ្ញុំបានសម្រេចចិត្តជ្រើសរើសយកការអភិវឌ្ឍគម្រោង "General Online Store" ដែលជាប្រព័ន្ធលក់ទំនិញអនឡាញទំនើប ដើម្បីសិក្សា និងឆ្លើយតបទៅនឹងតម្រូវការទីផ្សារបច្ចុប្បន្ន។

## I. លំនាំដើម (Background)

គម្រោង "General Online Store" ត្រូវបានបង្កើតឡើងក្នុងគោលបំណងសិក្សាពីការអភិវឌ្ឍន៍ Web Application ដោយប្រើប្រាស់ភាសា PHP ក្នុងទម្រង់ Object-Oriented Programming (OOP) និង MVC Architecture។ ប្រព័ន្ធនេះផ្តោតទៅលើការផ្ដល់នូវបទពិសោធន៍ទិញទំនិញដ៏ល្អប្រសើរសម្រាប់អតិថិជន និងភាពងាយស្រួលក្នុងការគ្រប់គ្រងទិន្នន័យសម្រាប់ម្ចាស់អាជីវកម្មក្នុងយុគសម័យឌីជីថល។

## II. បញ្ហាដែលបានជួបប្រទះ (Problem Statements)

តាមរយៈការសិក្សា និងសង្កេតលើការលក់ដូរតាមបែបប្រពៃណី និងហាងតូចៗមួយចំនួន យើងឃើញថាម្ចាស់អាជីវកម្មតែងតែជួបប្រទះបញ្ហាមួយចំនួនក្នុងការគ្រប់គ្រងដូចខាងក្រោម៖
- ពិបាកក្នុងការរក្សាទុក និងគ្រប់គ្រងទិន្នន័យផលិតផលដែលមានចំនួនច្រើន និងមានការភាន់ច្រឡំ។
- ការកត់ត្រាព័ត៌មានអតិថិជន និងការបញ្ជាទិញដោយដៃ ងាយនឹងមានកំហុសឆ្គង និងបាត់បង់ទិន្នន័យ។
- ភាពយឺតយ៉ាវក្នុងការត្រួតពិនិត្យស្តុកទំនិញ ដែលធ្វើឱ្យមានការខ្វះខាតទំនិញសម្រាប់លក់។
- មិនមានការធ្វើរបាយការណ៍ (Report) នៃប្រាក់ចំណូលឱ្យបានច្បាស់លាស់ និងរហ័ស។
- អតិថិជនមានការលំបាកក្នុងការចូលមើលព័ត៌មានលម្អិតនៃផលិតផល តម្លៃ និងរូបភាពពីចម្ងាយ។
- មានភាពយឺតយ៉ាវ និងកំហុសឆ្គងក្នុងការចេញវិក្កយបត្រជូនអតិថិជន។

## III. គោលបំណង (Objective)

ដើម្បីដោះស្រាយបញ្ហាមួយចំនួនដែលកំពុងតែជួបប្រទះខាងលើ ក្រុមយើងខ្ញុំនឹងកសាងប្រព័ន្ធ "General Online Store" នេះឡើងដើម្បីផ្តល់ភាពងាយស្រួលក្នុងការគ្រប់គ្រង។ ប្រព័ន្ធរបស់យើងនឹងជួយសម្រួលដល់ដំណើរការដូចខាងក្រោម៖
- ងាយស្រួលក្នុងការបញ្ចូល រក្សាទុក និងកែប្រែព័ត៌មានផលិតផល និងប្រភេទផលិតផល។
- ជួយសម្រួលដល់អតិថិជនក្នុងការស្វែងរកផលិតផល បន្ថែមចូលរទេះ និងបញ្ជាទិញបានយ៉ាងរហ័សទាន់ចិត្ត។
- ធ្វើឱ្យទិន្នន័យទាំងអស់មានសុវត្ថិភាពខ្ពស់ មិនព្រួយបារម្ភចំពោះការបាត់បង់ទិន្នន័យសមាជិក និងប្រវត្តិលក់។
- មានការធ្វើរបាយការណ៍លក់ និងគ្រប់គ្រងស្តុកទំនិញឱ្យមានសណ្តាប់ធ្នាប់ និងច្បាស់លាស់។
- មានការចេញវិក្កយបត្រដល់អតិថិជនដោយប្រព័ន្ធកុំព្យូទ័រ ដែលមានភាពរហ័ស និងមិនមានភាពភាន់ច្រឡំ។
- ផ្តល់ជូនមុខងារពហុភាសា (ខ្មែរ-អង់គ្លេស) និង Dark/Light Mode ដើម្បីបង្កើនភាពទាក់ទាញដល់អ្នកប្រើប្រាស់។

## IV. វិសាលភាព និងកម្រិតកំណត់ (Scope & Limitation)

ការគ្រប់គ្រងទៅលើអាជីវកម្មអនឡាញពិតជាមានភាពស្មុគស្មាញ។ ដោយសារតែពួកយើងចង់ផ្តោតទៅលើការរៀនសូត្រពីស្តង់ដារកូដ (MVC) និងបទពិសោធន៍ដំបូងក្នុងការកសាងប្រព័ន្ធនេះ ដូច្នេះប្រព័ន្ធមិនទាន់អាចគ្រប់គ្រងទៅលើគ្រប់បញ្ហាទាំងអស់បាននៅឡើយទេ។ អាស្រ័យហេតុនេះ យើងសូមកំណត់វិសាលភាពដូចខាងក្រោម៖

**វិសាលភាព (Scope):**
- គ្រប់គ្រងលើការចុះឈ្មោះ និងចូលប្រើប្រាស់របស់អ្នកប្រើប្រាស់ (Admin & Customer)។
- គ្រប់គ្រងផលិតផល (CRUD) និងការបែងចែកប្រភេទផលិតផល។
- ប្រព័ន្ធរទេះទំនិញ (Shopping Cart) និងការបញ្ជាទិញ (Checkout)។
- ការចេញវិក្កយបត្រ និងការត្រួតពិនិត្យស្ថានភាពបញ្ជាទិញ។

**កម្រិតកំណត់ (Limitation):**
- មិនទាន់មានមុខងារទូទាត់ប្រាក់តាមរយៈធនាគារដោយផ្ទាល់ (Payment Gateway Integration) ដូចជា ABA ឬ Wing ជាដើម។
- មិនទាន់មានមុខងារផ្ញើសារ (Chat) ផ្ទាល់រវាងអតិថិជន និងអ្នកលក់។
- មិនទាន់មានមុខងារគ្រប់គ្រងលើប្រាក់ខែបុគ្គលិក និងការចំណាយផ្សេងៗក្រៅពីការលក់។

ដូចនេះ សូមសិស្សានិស្សិតជំនាន់ក្រោយ សិក្សាស្វែងយល់បន្ត និងធ្វើការដោះស្រាយបញ្ហាដែលនៅខ្វះខាតនេះបន្ថែមទៀត។
