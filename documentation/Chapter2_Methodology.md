# ជំពូកទី ២៖ វិធីសាស្រ្តនៃការស្រាវជ្រាវ (Chapter II: Methodology of research)

## ២.១ តំបន់សិក្សា (Study Area)
ការសិក្សាស្រាវជ្រាវនេះផ្តោតទៅលើប្រព័ន្ធពាណិជ្ជកម្មតាមអេឡិចត្រូនិក (E-commerce System) នៅក្នុងប្រទេសកម្ពុជា ដើម្បីស្វែងយល់ពីតម្រូវការរបស់អ្នកប្រើប្រាស់ក្នុងស្រុក ជាពិសេសការប្រើប្រាស់ភាសាខ្មែរ និងទម្រង់រចនាដែលងាយស្រួលយល់។

## ២.២ ការប្រមូលទិន្នន័យ (Data Collection)

### ១. ទិន្នន័យបឋម (Primary Data)
*   ការសង្កេតមើលគេហទំព័រលក់ទំនិញល្បីៗ និងការសាកសួរអ្នកប្រើប្រាស់អំពីភាពងាយស្រួល។
*   ការសាកល្បងប្រើប្រាស់ផ្ទាល់លើប្រព័ន្ធគ្រប់គ្រងការលក់ដែលមានស្រាប់។

### ២. ទិន្នន័យបន្ទាប់បន្សំ (Secondary Data)
*   ការសិក្សាឯកសារបច្ចេកទេសអំពី PHP MVC ពីគេហទំព័រផ្លូវការ និងសហគមន៍អ្នកអភិវឌ្ឍន៍ (GitHub, StackOverflow)។
*   ការស្រាវជ្រាវអំពីស្ថាបត្យកម្មមូលដ្ឋានទិន្នន័យពីសៀវភៅ និងមេរៀនអនឡាញ។

## ២.៣ សកម្មភាព (Action)

### ១. ឧបករណ៍ដែលប្រើប្រាស់ (Tools)
*   **Editor:** VS Code ឬ PHPStorm
*   **Server:** XAMPP (Apache, MySQL)
*   **Frontend:** Tailwind CSS, Font Awesome
*   **Backend:** PHP 8 (OOP & MVC)

### ២. គំរូមូលដ្ឋានទិន្នន័យ (Database Models)
មូលដ្ឋានទិន្នន័យត្រូវបានរចនាឡើងជា Relational Database ដោយបែងចែកតារាងតាមមុខងារនីមួយៗដូចជា `users`, `products`, `categories`, `orders`, និង `order_items`។

### ៣. តម្រូវការផ្នែករឹង (Hardware Requirements)
*   **CPU:** Intel Core i3 ឬខ្ពស់ជាងនេះ។
*   **RAM:** 4GB ឬលើសពីនេះ។
*   **Storage:** ទំហំទំនេរយ៉ាងតិច 500MB។

### ៤. ផែនការការងារ (Work Plan)
*   សប្តាហ៍ទី ១៖ វិភាគតម្រូវការ និងរចនា Database។
*   សប្តាហ៍ទី ២៖ រៀបចំ Core MVC Structure។
*   សប្តាហ៍ទី ៣៖ បង្កើតផ្នែក Admin និង Product Management។
*   សប្តាហ៍ទី ៤៖ បង្កើតផ្នែក Shopping Cart និង Checkout។
*   សប្តាហ៍ទី ៥៖ ធ្វើតេស្តប្រព័ន្ធ និងរៀបចំឯកសារ។
