# ជំពូកទី ៤៖ សេចក្តីសន្និដ្ឋាន (Chapter IV: Conclusion)

បន្ទាប់ពីបានសិក្សា ស្រាវជ្រាវ និងអនុវត្តផ្ទាល់លើការបង្កើតប្រព័ន្ធ "E-Shop — PHP MVC" មក យើងអាចសន្និដ្ឋានបានថា ប្រព័ន្ធនេះបានសម្រេចតាមគោលបំណងដែលបានកំណត់ទុក។

## សមិទ្ធផលសំខាន់ៗ៖
*   ប្រព័ន្ធអាចដំណើរការមុខងារទិញ-លក់បានយ៉ាងរលូន។
*   ផ្នែកគ្រប់គ្រងស្តុកមានភាពច្បាស់លាស់ និងមានការដាស់តឿនទាន់ពេលវេលា។
*   ស្ថាបត្យកម្ម MVC ធ្វើឱ្យកូដមានភាពងាយស្រួលក្នុងការថែទាំ និងកែសម្រួល។

## បញ្ហាប្រឈម និងដំណោះស្រាយ៖
ក្នុងអំឡុងពេលអភិវឌ្ឍ យើងបានជួបការលំបាកខ្លះៗលើការគ្រប់គ្រង Session និងការធ្វើ Localization (ភាសាខ្មែរ) ប៉ុន្តែតាមរយៈការពិគ្រោះជាមួយឯកសារយោង និងការធ្វើតេស្តម្តងហើយម្តងទៀត យើងបានរកឃើញដំណោះស្រាយដ៏ល្អប្រសើរ។

ជាចុងក្រោយ គម្រោងនេះមិនត្រឹមតែជាកម្មវិធីសម្រាប់ប្រើប្រាស់ប៉ុណ្ណោះទេ ប៉ុន្តែវាក៏ជាមូលដ្ឋានគ្រឹះដ៏សំខាន់សម្រាប់ពួកយើងក្នុងការបង្កើនចំណេះដឹងផ្នែក Programming ឱ្យកាន់តែស៊ីជម្រៅថែមទៀត។
